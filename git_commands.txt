================================================================================
GIT COMMAND DOCUMENTATION - ASSIGNMENT REFERENCE
Repository: https://github.com/Sachith77/bits-git-assignment
================================================================================

1. git init -b main
   Initializes a new local Git repository inside the project folder with the
   default branch named 'main'.

2. git status
   Displays the state of the working directory and staging area, highlighting
   untracked, modified, or staged files.

3. git add .
   Stages all new, modified, and deleted files in the working directory,
   preparing them for the upcoming commit.

4. git commit -m "Initial commit: Add index.html and about.html"
   Records the staged snapshot of index.html and about.html into repository
   history with a descriptive message.

5. git add index.html
   Stages the updated index.html containing the new sections for the second commit.

6. git commit -m "Update index.html: Add key topics covered section"
   Creates the second commit on the main branch, recording modifications made to
   index.html.

7. git branch feature
   Creates a new branch named 'feature' branching off from the current commit of
   the main branch.

8. git switch feature (or git checkout feature)
   Switches the active working branch from 'main' to 'feature', updating HEAD and
   working tree files.

9. git branch
   Lists all local branches in the repository and marks the currently active
   branch with an asterisk (*).

10. git add about.html
    Stages modifications made to about.html while working on the isolated
    'feature' branch.

11. git commit -m "Enhance about.html: Add branching strategy details on feature branch"
    Records the commit containing the new about.html content directly onto the
    'feature' branch.

12. git switch main (or git checkout main)
    Switches the active branch back to 'main' in preparation for integrating the
    feature branch changes.

13. git merge --no-ff feature -m "Merge branch 'feature' into main"
    Merges the 'feature' branch into 'main' using a dedicated merge commit
    (--no-ff) to preserve branch history.

14. git log --graph --oneline --all
    Displays a compact graphical view of the commit history across all branches
    showing divergence and merge points.

15. git status --ignored
    Displays working directory status including files deliberately ignored
    according to rules defined in .gitignore.

16. git add .gitignore
    Stages the newly created .gitignore file containing exclusion rules for
    *.log and temp/.

17. git commit -m "Configure .gitignore: Ignore *.log files and temp/ directory"
    Records .gitignore into version control history so that ignore rules are
    tracked and shared.

18. git add experimental.html
    Stages a temporary experimental file created specifically to demonstrate an
    undo operation.

19. git commit -m "Add experimental feature for undo testing"
    Records the experimental commit that will subsequently be undone.

20. git revert HEAD --no-edit
    Undoes the previous commit safely by creating a new inverse commit, removing
    experimental.html while preserving audit history.

21. git reset HEAD~1 (Alternative Undo Command)
    Moves HEAD and the branch pointer back by one commit; used locally when
    commits have not yet been pushed to a remote.

22. git remote add origin https://github.com/Sachith77/bits-git-assignment.git
    Associates the local Git repository with the newly created remote public
    repository hosted on GitHub.

23. git remote -v
    Lists all configured remote connections along with their fetch and push target URLs.

24. git push -u origin main
    Pushes the complete 'main' branch commit history to GitHub and establishes
    upstream tracking.

25. git push -u origin feature
    Pushes the local 'feature' branch to GitHub so all branching history and
    commits are visible remotely.
